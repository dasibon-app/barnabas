한 줄 요약
바나바는 개발자의 서버가 없는 앱입니다. 입력하신 모든 자료는 사용자 본인의 구글 드라이브와 사용자의 기기에만 저장되며, 개발자는 그 내용을 볼 수도, 가져갈 수도 없습니다. 광고·분석 도구·제3자 제공은 없습니다.

결제(구독·평생 이용)는 Google Play가 처리하며, 운영자는 카드번호 등 결제 정보를 받거나 보관하지 않습니다.

앱은 주민등록번호를 저장하지 않습니다. 기부금 영수증 발급 시 입력한 값은 해당 발급 파일에만 들어가고 앱 자료로 저장되지 않습니다.

3. 구글 사용자 데이터 이용 (Google API 서비스 사용자 데이터 정책)

  • 앱은 구글 로그인과 함께 https://www.googleapis.com/auth/drive.file 권한 하나만 요청합니다. 이 권한으로는 앱이 만들었거나 사용자가 직접 고른 파일만 열 수 있으며, 사용자의 다른 드라이브 파일은 볼 수 없습니다.
  • 이 권한은 교회 자료 파일의 저장·읽기, 영수증 사진 보관, 구글 시트 내보내기, 공동 관리자·사역자와의 파일 공유에만 사용합니다.
  • 구글 사용자 데이터를 운영자 또는 제3자의 서버로 전송하지 않으며, 광고, 신용 평가, 데이터 중개에 쓰지 않습니다. 사람이 읽는 일도 없습니다. 다만 사용자가 직접 초대한 공동 관리자·사역자는 사용자가 허락한 범위의 자료를 볼 수 있습니다.
  • 바나바가 구글 API로부터 받은 정보의 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 기기 권한

  • 인터넷: 구글 드라이브와 동기화하기 위해 사용합니다.
  • 카메라·사진: 앱은 카메라·저장소 접근 권한을 따로 요청하지 않습니다. 영수증·직인 사진을 붙일 때 기기의 선택 화면이 열리고, 사용자가 고른 사진만 앱에 전달됩니다.

5. 보관 기간과 삭제

  • 자료는 사용자가 삭제하기 전까지 사용자의 구글 드라이브와 기기에 남습니다. 운영자는 자료를 별도로 보관하지 않습니다.
  • 앱 자료 삭제: 구글 드라이브의 ‘바나바 교회자료’ 폴더를 삭제하면 됩니다.
  • 앱의 접근 권한 취소: 구글 계정 설정(myaccount.google.com/permissions)에서 ‘바나바’의 접근 권한을 삭제하면 앱은 더 이상 드라이브에 접근할 수 없습니다.
  • 기기 안의 자료 삭제: 앱을 삭제하면 기기 안의 임시 저장 자료가 지워집니다.
  • 공동 관리자·사역자 접근은 앱의 ‘연동’ 화면에서 참여자를 해제하거나 구글 드라이브 공유 설정에서 해당 사용자를 제거해 끊을 수 있습니다.

6. 제3자 제공·위탁·국외 이전

운영자는 사용자의 정보를 제3자에게 제공하거나 처리 위탁하지 않습니다. 자료의 저장과 전송은 사용자 본인이 이용하는 구글 서비스(Google LLC)를 통해 이루어지며, 이에 대해서는 구글 개인정보처리방침이 적용됩니다. 구글 서버는 국외에 있을 수 있습니다. 앱 결제는 Google Play(Google LLC)를 통해 처리되며 구글 개인정보처리방침이 적용됩니다.

7. 교회 성도 정보에 관한 안내 (중요)

앱에 입력하는 성도의 이름·연락처·생일 등은 해당 교회가 수집·관리하는 개인정보입니다. 운영자는 그 내용을 알지 못하며, 앱은 교회가 쓰는 도구일 뿐입니다. 따라서 성도 정보의 수집·이용에 대한 동의 확보, 접근 권한 관리(누구를 공동 관리자·사역자로 초대할지), 보관과 파기는 교회(사용자)의 책임입니다.

  • 만 14세 미만 아동의 정보를 입력할 때는 법정대리인(부모)의 동의를 받아 주세요.
  • 민감한 내용(심방 일지, 건강·가정 사정 등)은 꼭 필요한 만큼만 적고, 폰에 화면 잠금을 설정해 주세요.
  • 초대하는 분에게는 개인정보 보호 의무가 있음을 알려 주세요.

8. 안전성 확보 조치

앱은 구글 로그인 인증과 구글 드라이브의 접근 권한 체계를 이용해 자료를 보호합니다. 통신은 암호화(HTTPS)됩니다. 백업 파일에는 사용자가 암호를 걸 수 있는 기능이 있습니다. 기기 분실에 대비해 기기 잠금과 정기 백업을 권장합니다.

9. 이용자의 권리

사용자는 언제든 자신의 자료를 열람·수정·삭제할 수 있으며(앱 또는 구글 드라이브에서), 위 5항의 방법으로 앱의 접근을 철회할 수 있습니다. 운영자는 사용자 자료를 보유하지 않으므로 운영자에게 별도로 열람·삭제를 요청할 필요가 없습니다. 문의는 위 이메일로 해 주세요.
